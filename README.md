# hair salon 凪（なぎ）— 美容院サイト テンプレート

福岡市西区にある架空の美容院「hair salon 凪」のデモサイトです。
営業時に「このくらいのサイトが作れます」と見せるためのサンプルであり、
**同時に他店舗へ使い回せるテンプレート**として作ってあります。

- 公開 URL: https://kaomatsu8888.github.io/-beauty_salon_site_create/
- 技術: HTML / CSS / バニラ JavaScript のみ（ビルド不要・依存パッケージなし）
- 想定閲覧環境: スマートフォン（幅 375px を基準に設計）

> このサイトに登場する店名・住所・電話番号・スタイリスト名・料金はすべて架空です。

---

## 1. ファイル構成

```
.
├ index.html        骨組みのみ。店舗のテキストは持たない
├ css/style.css     配色・余白・フォントは :root の CSS 変数に集約
├ js/data.js        ★店舗情報はすべてここ。差し替え作業の主役
├ js/hours.js       営業時間データから「営業中／終了」を判定
├ js/render.js      data.js → DOM に描画。構造化データもここで生成
├ js/app.js         営業中表示の反映・スクロール演出・固定バー制御
├ images/           ダミー画像（SVG）。同名の写真に差し替える
└ README.md
```

設計の要点は **店舗固有のテキストを `index.html` に書かない** ことです。
`index.html` には `data-bind="salon.name"` のような目印だけが置かれ、
`render.js` が `data.js` の値を流し込みます。
そのため、別店舗へ転用するときに触る場所が `data.js` にほぼ集約されます。

## 2. 別の店舗用に書き換える手順

### 手順 1: `js/data.js` を書き換える

このファイルがサイトの中身そのものです。**値だけ**を書き換えてください。
プロパティ名（`salon`, `menu`, `staff` など）を変えると描画が壊れます。

| ブロック | 書き換える内容 |
|---|---|
| `salon` | 店名・キャッチコピー・住所・電話番号・価格帯・各種リンク |
| `salon.links` | `reserve`（予約サイト）/ `line` / `instagram` の URL。`#dummy-...` のままだとリンクは動きません |
| `salon.mapEmbedSrc` | Google マップの埋め込み URL（後述）。空のままなら枠だけ表示されます |
| `hours` | 営業時間・定休日（後述） |
| `firstTime` | 「初めての方へ」の項目。`items` は増減自由です |
| `menu` | カテゴリとメニュー。`price` は**税込の数値**で書きます（`4800` → `¥4,800` と表示） |
| `staff` | スタイリスト。`members` の要素数で 1 名でも 5 名でも対応します |
| `gallery` | スタイル写真。要素数は自由（3 の倍数が PC で揃います） |
| `access` | 電車・バス・車でのアクセスと目印 |
| `faq` | よくある質問。アコーディオンの数は `items` の数に追従します |
| `seo.siteUrl` | 公開先の URL（末尾のスラッシュまで含める） |

### 手順 2: 営業時間と定休日を直す

`hours.weekly` は **日曜から土曜の 7 要素**です。休業日は `null` を入れます。

```js
hours: {
  weekly: [
    { open: '09:00', close: '18:00' }, // 日
    { open: '09:30', close: '19:00' }, // 月
    null,                              // 火 ← 定休日
    { open: '09:30', close: '19:00' }, // 水
    { open: '09:30', close: '19:00' }, // 木
    { open: '09:30', close: '20:00' }, // 金
    { open: '09:00', close: '19:00' }, // 土
  ],
  irregularClosed: [{ nth: 3, weekday: 3 }], // 第3水曜も休み
  closedLabel: '毎週火曜・第3水曜',           // 画面に出す文字
  lastOrderMinutes: 30,                      // 受付終了を閉店の何分前にするか
}
```

- `irregularClosed` は「第 n 何曜日」を追加の休みにする規則です。
  `weekday` は 0=日 … 6=土。第 2・第 4 月曜なら
  `[{ nth: 2, weekday: 1 }, { nth: 4, weekday: 1 }]` と書きます。
  不定休がない店舗なら `[]` にしてください。
- `closedLabel` は表示用の文字列です。`weekly` や `irregularClosed` を変えても
  自動では変わらないため、**セットで書き換えてください**。
- 画面上部と予約セクションの「営業中／本日は終了しました」は
  `weekly` と `irregularClosed` から自動で計算されます。
- 営業時間の表（店舗情報セクション）は、同じ時間帯の連続した曜日を
  「月〜木 9:30 - 19:00」のようにまとめて表示します。手で書く必要はありません。

### 手順 3: `index.html` の `<head>` を書き換える

ここだけは `data.js` と別に手で直します。
SNS のシェアプレビューや検索クローラは JavaScript を実行せずに
`<head>` を読むため、JS で後から書き込んでも間に合わないからです。

`index.html` の冒頭、`<!-- 【注意】 -->` のコメント直後にある次の 8 箇所です。

1. `<title>` — 「店名｜エリア＋業種」の形が検索結果で読みやすい
2. `<meta name="description">` — 全角 60〜80 文字程度
3. `<link rel="canonical">` — 公開 URL
4. `<meta property="og:site_name">` — 店名
5. `<meta property="og:title">`
6. `<meta property="og:description">`
7. `<meta property="og:url">` — 公開 URL
8. `<meta property="og:image">` — OGP 画像の**絶対 URL**（相対パスは効きません）

構造化データ（`HairSalon`）は `data.js` から自動生成されるため、
手で書き換える必要はありません。

### 手順 4: 画像を差し替える

`images/` 内のダミーは SVG です。**同じファイル名で写真を置き、
`js/data.js` の拡張子を `.svg` → `.jpg` に変えてください。**

| ファイル | 用途 | 推奨サイズ | data.js の該当箇所 |
|---|---|---|---|
| `hero.svg` | ファーストビュー | 1200 × 900 以上 | `images.hero` |
| `staff-01〜03.svg` | スタイリスト | 480 × 600（4:5） | `staff.members[].image` |
| `gallery-01〜06.svg` | スタイル写真 | 480 × 600（4:5） | `gallery.items[].image` |
| `og.svg` | SNS シェア画像 | 1200 × 630 | `index.html` の `og:image` |
| `favicon.svg` | タブのアイコン | 64 × 64 | `index.html` の `rel="icon"` |

- 写真は CSS 側で `object-fit: cover` でトリミングされるため、
  縦横比が多少違っても崩れません。
- `alt` 属性も `data.js`（`imageAlt` / `alt`）から出しています。
  写真を変えたら説明文も直してください。
- 画像は JPEG なら品質 80 前後、長辺 1200px 以内が目安です。
  ヒーロー以外は遅延読み込み（`loading="lazy"`）が入っています。

### 手順 5: 配色を変える

`css/style.css` の冒頭 `:root` にある変数だけを触ります。

```css
--accent: #6e7f6a;       /* 予約ボタン・リンク・見出しの色 */
--accent-dark: #55634f;  /* ホバー時と文字色。背景が白のとき使う */
--accent-pale: #e9eee7;  /* タグや予約セクションの淡い背景 */
```

**アクセント色は 1 色だけに保ってください。** 色数を増やすと途端に
量産テンプレートの見た目になります。雰囲気を変えたいときは
アクセントの色相を変えるだけで十分です。

色を変えたら、`--accent` の上に白文字を乗せたときの
コントラスト比が **4.5:1 以上**あることを確認してください
（WebAIM Contrast Checker などで確認できます）。
これを下回ると予約ボタンの文字が読みづらくなります。

`index.html` の `<meta name="theme-color">` も背景色に合わせて直します。

### 手順 6: 地図を入れる

1. Google マップで店舗を検索 → 「共有」→「地図を埋め込む」
2. 表示される `<iframe src="...">` の **`src` の中身だけ**をコピー
3. `js/data.js` の `salon.mapEmbedSrc` に貼る

空文字のままなら、住所を書いたプレースホルダ枠が表示されます。
営業デモの段階ではこのままでも問題ありません。

## 3. ローカルでの確認

`file://` で直接開いても動きますが、ローカルサーバー経由を推奨します。

```bash
cd beauty-salon-site
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

スマホ表示の確認は、ブラウザの開発者ツールでデバイス幅を **375px** にします。
確認したいポイント:

- 画面下の固定バー（予約／電話／LINE）が少しスクロールすると現れる
- ヘッダー右の営業状態バッジが現在時刻に合っている
- メニュー表の料金が右端で揃っている
- 横スクロールが発生していない

## 4. GitHub Pages で公開する

```bash
git add -A
git commit -m "店舗情報を更新"
git push
```

初回のみ、GitHub のリポジトリ画面で設定します。

1. **Settings** → **Pages**
2. **Source** を `Deploy from a branch` にする
3. **Branch** を `main` / `/ (root)` にして **Save**
4. 1〜2 分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

別店舗用に使い回すときは、このリポジトリを GitHub の
**Use this template** もしくは fork で複製してから `data.js` を書き換えると、
元のデモサイトを残したまま新しいサイトを作れます。

## 5. 設計上の決まりごと

転用時に壊さないよう、次の 4 点は守ってください。

1. **`index.html` に店舗のテキストを直接書かない。**
   書いてしまうと差し替え箇所が 2 つに分かれ、テンプレートの意味が失われます。
2. **`data.js` のプロパティ名を変えない。** `render.js` が名前で参照しています。
3. **本文は 16px 以上、タップできる要素は 44px 以上を保つ。**
   来店者の多くが 30〜40 代以上のスマホ利用者である前提の数字です。
4. **アニメーションを増やさない。** `prefers-reduced-motion` への対応と、
   「落ち着いた店」という印象を両立させるため、演出は
   8px のフェードインのみに抑えています。
